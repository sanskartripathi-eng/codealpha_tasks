Music Player

About the Project

This project is a web-based Music Player developed using HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship.

It provides a simple and interactive interface for playing and controlling audio tracks.

Technologies Used

HTML5
CSS3
JavaScript
Features

Modern music player interface.
Play and pause functionality.
Next and previous track controls.
Song title and artist information.
Audio progress bar.
Volume control.
Playlist functionality.
Autoplay support.
Learning Outcomes

Event listeners.
